# 🏢 Enterprise Asset & Auction Management Dashboard

## 📌 Project Overview
This is a comprehensive, multi-page Business Intelligence report designed to track enterprise assets, auction statuses, and sales performance. The project demonstrates advanced Power BI capabilities, moving beyond single flat-file analysis into complex **Data Modeling (Star Schema)**, **ETL via Power Query**, and **Interactive UI/UX** using bookmarks and page navigation.

### 🛠️ Tech Stack & Skills Demonstrated
* **ETL & Data Prep (Power Query):** Cleaned and transformed raw data across 5 distinct tables to ensure data integrity.
* **Relational Data Modeling:** Built a robust Star Schema (1-to-Many relationships) to seamlessly connect Asset, Auction, Sales, and Calendar/Date dimension tables.
* **Advanced Visualization:** Designed an app-like experience in Power BI using Bookmarks, Page Navigation, and custom DAX measures for KPIs.

## 💡 Key Business Solutions Built
* **Dynamic Page Navigation:** Implemented custom button-based navigation (Summary, Auctions, Sales) for a seamless user experience without cluttering a single page.
* **Time Intelligence:** Integrated Date tables to track Month-over-Month (MoM) asset sales and auction closures accurately.
* **Target vs. Actual Tracking:** Categorized multi-billion dollar target values against actual sales to highlight variance, committee performance, and workflow bottlenecks.
